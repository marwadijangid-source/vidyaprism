VIDYAPRISM COMPLETE MULTI-PAGE WEBSITE
======================================

Open index.html to start.

Pages included:
- index.html — Homepage
- explore.html — working quizzes, grade/subject filters, search, feedback and local score history
- subjects.html — Std 9–12 learning areas
- daily-challenge.html — date-rotating reasoning challenge
- about.html — VIDYAPRISM mission and founder details
- contact.html — official channel links

Assets:
- assets/css/style.css
- assets/js/app.js
- assets/js/quizzes.js

Important:
- This is a complete static website frontend. All included navigation links and local interactions work without a server.
- Quiz questions are original practice questions written for this site; they are not represented as official GSEB textbook questions or a complete syllabus.
- Scores are stored in localStorage on the current browser/device only. There is no student account, cloud sync, teacher dashboard, cross-device leaderboard or server database.
- The site can be hosted on GitHub Pages or any static web host. Keep the folder structure unchanged.
- Google Fonts require an internet connection; fallback fonts are defined.
- PageSpeed Insights has not yet been run on a deployed URL. Performance score must be measured after publishing.
